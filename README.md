Glasshouse Ghost — a top-down stealth game in the browser. Sneak through three wings of a botanical glasshouse at night, steal the Moon Orchid in each one, and reach the exit unseen. Watchmen patrol with lantern vision cones that bend around crates and planters; fern shade and sneaking slow detection, pebbles pull eyes away, and a filling detection eye gives you a chance to break line of sight and recover. Keyboard and mouse, synthesized WebAudio sound, no build step and no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
